# デュエマ フリー対戦 (`/duel`)

ルール処理を持たない「対戦卓」です。カードを自由に動かして、相手と盤面をリアルタイムで共有します。

## 使い方
1. プレイヤー名・デッキリスト（`4 カード名` を1行ずつ、超次元は先頭に `超`）を入力
2. モードを選ぶ
   - **オンライン対戦**: 同じルームIDの相手と Supabase Realtime で同期（招待リンク `/duel?room=xxx`）
   - **同じブラウザの別タブ**: BroadcastChannel で同期。1台で動作確認用
   - **一人回し**: 相手なし
3. 入室すると自動でシャッフル → シールド5枚 → 手札5枚

## 操作
- ドラッグ: 好きなゾーンへ移動（バトルゾーン内は自由配置）
- バトルゾーン／マナのカードをクリック: タップ／アンタップ
- 右クリック・長押し・手札クリック: メニュー（裏返す、山札の上／下へ、相手に見せる など）
- 山札クリック: 1枚ドロー。「山札 ▾」でサーチ・上からX枚見る・マナ／墓地／シールド送り
- 墓地・超次元クリック: 一覧（相手の墓地も閲覧可）

## 同期の仕組み
- 各プレイヤーが自分の盤面を持ち、変更のたびに**公開情報だけ**を broadcast（`transport.ts`）
- 手札と山札は枚数のみ、裏向きのカード（シールドなど）は名前を伏せて送信
- 盤面はタブの sessionStorage に保存されるので、再読み込みしても続きから再開できます
- DB テーブルは不要。Supabase プロジェクトで Realtime が有効であれば動きます
